# Get Count

<mark style="color:blue;">`GET`</mark> `http://localhost:8070/v1/metrics`

Get count of events emitted for each entityType

:::: tabs
== 200: OK Retrieve all the events for each entityType based grouped on the basis of operationType. Eg: {schema: { add: 5, read: 2}}
::::
