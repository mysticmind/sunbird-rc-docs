# Why do we need Sunbird RC?

Stand up trusted registries and verifiable credentials quickly — for any domain.

<div class="video-embed"><iframe src="https://www.youtube-nocookie.com/embed/zWDyQWuB_lw" title="Video" allowfullscreen loading="lazy"></iframe></div>

Sunbird RC lets you quickly build registries of individuals, objects and entities for a wide variety of domains.

::: info
Sunbird RC is one open-source package with two components, **Registry** and **Credentials**. You can use either one on its own, or both together. Each component has its own release line and version number.
:::

## Build registries through configuration

Adopters build core electronic registries using configurable schemas and workflows. Sunbird RC then automatically creates all the APIs, workflows and a default user experience needed by key registry stakeholders.

## Issue credentials people can carry and verify

Sunbird RC provides microservices to issue portable, standard schema-based credentials that are compliant with the [W3C Verifiable Credentials](https://www.w3.org/TR/vc-data-model/) data model, with built-in attestation and verification flows. Credentials can be issued from a Sunbird RC Registry or from any existing system of record. These credentials:

* can be printed with QR codes
* can be translated into many languages
* can be verified by anyone, using the issuer's public key

Along the way, Sunbird RC handles enrolment, authentication, data ownership, search, issuance and management of verifiable credentials, claim attestation between users and attesters, and sharing of credentials with user consent.
