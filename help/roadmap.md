# Roadmap

Sunbird RC is one package with two components, Registry and Credentials, which can be used on their own or together. Each component has its own release line. This page shows what is released today, what comes next, and what is planned later for each.

## Status labels

| Label              | Meaning                                                        |
| ------------------ | -------------------------------------------------------------- |
| **Released**       | Available in a published release and supported.                |
| **Experimental**   | Available, but may change; not recommended for production yet. |
| **In Development** | Actively being built; not yet in a release.                    |
| **Roadmap**        | Planned for a future release; scope may change.                |

## Current

* **Credentials v2.1.0** — Released. See the [v2.1.0 release notes](/use/releases/credentialing/v2.1.0-latest-release).
* **Registry v2.0.3** — Released. See the [v2.0.3 release notes](/use/releases/registry/v2.0.3).

## Next

* **Authority Service** (Registry + Credentials) — In Development. A domain-neutral administrative layer for multi-tenant access control, configuration and record review. Target release to be confirmed. See [Authority Service](/learn/core-capabilities#authority-service).
