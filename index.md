# From the former Welcome Aboard page
features:
  - title: Secure by Design
    details: Every credential is cryptographically signed, sensitive data is encrypted, and keys are managed in Vault.
  - title: Designed to Scale
    details: Independent microservices on Kubernetes can be scaled horizontally as a registry grows.
  - title: Resilient Under Load
    details: Entity creation can be processed asynchronously through Kafka to absorb spikes in demand.
  - title: Open by Default
    details: Built on W3C Verifiable Credentials and DIDs, with no vendor lock-in, so credentials can be verified anywhere.
  - title: Registries Without Code
    details: Define a schema, and Sunbird RC automatically generates the APIs, attestation workflows and credentials.
  - title: Instant Verification
    details: Anyone can verify a credential in seconds by scanning a QR code, even offline.

<div class="rc-home-about">

Sunbird RC is a best-in-class open-source framework for building electronic registries and issuing verifiable credentials. It enables governments and organisations to build trusted registries of people, institutions and assets, from teachers and health workers to schools, and keep that data accurate, verified and ready to use. Sunbird RC is part of Sunbird, a Digital Public Good, and gives every adopter a proven foundation for digital trust, so no one has to build it from scratch.
