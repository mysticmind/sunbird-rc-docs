# Sunbird RC documentation

Source for [rc.sunbird.org](https://rc.sunbird.org), built with [VitePress](https://vitepress.dev).
Every page is a Markdown file, and its path in this repo is its URL on the site:
`use/getting-started/installation.md` is `rc.sunbird.org/use/getting-started/installation`.

## Run it locally

You need Node.js 20 or later.

```bash
npm install
npm run dev        # live preview at http://localhost:5173
npm run build      # production build into .vitepress/dist
npm run preview    # serve the production build at http://localhost:4173
```

`npm run build` fails on broken internal links, so run it before opening a pull request.

## Fix or add a page

1. Click **Edit this page on GitHub** at the bottom of any page, or find the file using the URL.
2. Make the change and open a pull request against `main`.
3. To add a page, create the Markdown file and add it to `.vitepress/sidebar.json`
   (this file replaces GitBook's `SUMMARY.md`).
4. Start each page with front matter. The `description` is shown in search results and in `llms.txt`:

   ```markdown
   ---
   title: "Docker Compose Setup"
   description: "Run the full Sunbird RC stack on one machine with Docker Compose."
   ---
   ```

Images go in `public/images/` and are referenced as `/images/<name>.png`. Use lowercase names without spaces.

## What goes where

| Path | Contents |
| --- | --- |
| `learn/`, `use/`, `engage/`, `help/` | Knowledge base (the **Knowledge Base** tab) |
| `registry/` | Registry technical overview and API reference |
| `credentials/` | Credentials technical overview and API reference |
| `openapi/` | Copies of the OpenAPI specs from `sunbird-rc-core/api-documentation` |
| `public/` | Images, video and the logo, served as-is |
| `.vitepress/config.mts` | Site settings, navigation and plugins |
| `.vitepress/sidebar.json` | Sidebar for each section |
| `.vitepress/theme/` | Brand colours, styles and the `ApiOperation` component |
| `scripts/` | OpenAPI sync and the one-off GitBook migration |

## Writing syntax

Standard Markdown plus these VitePress blocks:

| Use | Syntax |
| --- | --- |
| Callout | `::: info`, `::: tip`, `::: warning`, `::: danger`, closed with `:::` |
| Tabs | `::: tabs`, then `== Tab title` before each tab |
| Same request in several clients (cURL, HTTPie) | `::: code-group` around fenced blocks titled like ` ```shell [cURL] ` |
| Numbered steps | `:::: steps` wrapping one `::: step` per step |
| Two columns | `:::: columns` wrapping two `::: column` blocks |
| Link card | `::: card` around a single link |
| API operation | `<ApiOperation spec="issue-api" path="/credentials/issue" method="post" />` |

When blocks are nested, the outer block needs more colons than the inner one.
To show `{{ }}` in text, wrap it in `<span v-pre>...</span>`, because VitePress pages are Vue templates.

## API reference

The Credentials API pages are generated from the OpenAPI specs in `openapi/`. Refresh them from
`sunbird-rc-core` with:

```bash
npm run sync-openapi            # from main
npm run sync-openapi -- v2.1.1  # from another branch
```

## For AI agents

Each build publishes [`/llms.txt`](https://rc.sunbird.org/llms.txt) (index of every page),
`/llms-full.txt` (the whole site in one file) and a `.md` version of every page, generated by
`vitepress-plugin-llms`.

## Migration from GitBook

The content was imported from the live GitBook site on 26 November 2026 with
`scripts/migrate-from-gitbook.py`. The script downloads each page's Markdown export, converts the
GitBook blocks (hints, tabs, steppers, columns, content refs, embeds, release updates and OpenAPI
blocks), downloads images from GitBook's CDN, and builds the sidebar from the live page order.
Page URLs are unchanged.

```bash
python3 scripts/migrate-from-gitbook.py /tmp/rc-gitbook . --fetch
```

Rerun it only while the GitBook site is still being edited. Once this repo is live, edit here.
